# Technology Skills Design — Current Atomic Catalog

The technology department owns nine atomic Skills:

1. `technology-requirement`
2. `technology-feasibility-assessment`
3. `technology-specification-confirmation`
4. `technology-solution-design`
5. `technology-task-breakdown`
6. `technology-development-implementation`
7. `technology-test-acceptance`
8. `technology-system-release`
9. `technology-operations-maintenance`

Specification confirmation fixes performance, interface, compatibility, security, acceptance, and procurement parameters. Solution design then defines architecture, components, data flow, deployment, observability, migration, and rollback without redefining those obligations.

Technology records use stable IDs, restricted artifact references, minimum metadata, explicit human confirmation, and append-only evidence. Source bodies, secrets, raw logs, dumps, and customer data are excluded. All packages live under `.agents/skills/`.
