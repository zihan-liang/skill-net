# HR Skills Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build and validate eight Codex HR skills that implement the supplied recruiting workflow and employee database.

**Architecture:** Store each capability in `skills/<skill-name>/` with a concise `SKILL.md` and generated `agents/openai.yaml`. Keep reusable templates in `assets/`, deterministic transformations in `scripts/`, the database schema in `references/`, and collection-wide contracts in `tests/`.

**Tech Stack:** Markdown, YAML, Python 3 standard library, SQLite, Codex skill-creator scripts

## Global Constraints

- Create exactly the eight packages listed in the design.
- Use only `name` and `description` in `SKILL.md` frontmatter.
- Start each description with `Use when` and describe trigger conditions only.
- Require human confirmation for external communication and consequential HR decisions.
- Do not use protected characteristics in candidate scoring.
- Do not push changes to GitHub.
