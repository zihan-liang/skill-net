# E1 All-21-Tasks Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Expand every E1 condition from the former five-task subset to the complete ordered GT01–GT21 inventory while preserving size-46 E0 reuse and existing evaluator semantics.

**Architecture:** Keep `E1_scale_manifest.json` as the E1 task-inventory source. Make runner and verifier reject inventories that differ from canonical prompt/Gold IDs, generate a renamed frozen 21-task E1 Gold package, and exercise the artifact pipeline with 21-task fixtures. Documentation will describe 126 new size-10/30 calls and E0 reuse for size 46.

**Tech Stack:** Python 3.9.6, `unittest`, JSON, existing SkillNet runner/verifier and deterministic evaluator.

## Global Constraints

- Implement `docs/superpowers/specs/2026-07-30-e1-all-21-tasks-design.md` exactly.
- E1 size 10 and 30 run GT01–GT21 for A/B/C: 126 later formal model calls.
- E1 size 46 starts no child and reuses all 21 formal E0 outcomes.
- Missing required Skills in smaller Catalogues remain evaluator failures; do not filter them.
- Do not modify Catalogues, relations, canonical Gold task records, schema, evaluator rules, Skills, or E0 artifacts.
- Do not start real Codex children during implementation; use fixture-only temporary state roots.
- Preserve one-shot behavior: no retry, resume, supplement, output repair, or patched formal result.
- Use `experiments/skillnet/.venv/bin/python` for runner/verifier tests.
