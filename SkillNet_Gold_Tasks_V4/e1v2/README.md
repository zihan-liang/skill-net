# SkillNet E1-v2 Frozen Gold

`E1V2_Gold_21.json` contains 18 JSON-value-identical compatible records from
the original 21-task Gold plus three new scale-compatible short tasks. It is a
new experiment package and does not replace the original Gold or frozen E1
five-task subset.

`gold_relevant_skills.json` records each relevant Skill, its count, and every
Gold source field that made it relevant. `prompts/` contains one frozen
bilingual prompt file per E1-v2 task.

The three new tasks were designed before any formal E1-v2 model response and
have new task IDs. Their provenance is stored in each task record.
